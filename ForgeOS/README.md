# Linux Process Monitoring and Control System

## OSSP Project

This project is a Linux-based system programming application for monitoring and controlling running processes.

## Project Scope

The system will provide a terminal-based interface to:

- List running Linux processes
- Display process information
- Inspect a selected process
- Pause a process
- Resume a process
- Gracefully terminate a process
- Forcefully terminate a process

## Linux/POSIX Technologies

The implementation will use C on Ubuntu/Linux and will demonstrate:

- Linux `/proc` filesystem
- POSIX/Linux file and directory interfaces
- File descriptors and file I/O
- Linux system calls
- Process management
- Linux signals
- `SIGSTOP`
- `SIGCONT`
- `SIGTERM`
- `SIGKILL`
- GDB
- strace
