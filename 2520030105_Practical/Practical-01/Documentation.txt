Objective:
To understand process creation and execution of a Linux command using
fork(), exec(), and wait() system calls.

Requirements:
1. Create a child process using fork().
2. Display the process ID of the parent and child.
3. Use exec() to execute a Linux command from the child process.
4. Use wait() so that the parent waits for the child process to complete.
5. Observe the relationship between the parent and child processes.

Concepts Used:
- Process creation using fork()
- Process identification using getpid() and getppid()
- Command execution using execlp()
- Parent-child synchronization using wait()
- Error handling using perror()
