# Creaters_Shell_OSSP

## OSSP Project

### Linux Process Monitoring and Control System

The project is developed as a Linux-based system programming application using C and Linux/POSIX interfaces.

### Project Directory

The project is maintained in:

### Project Documentation

### Core Technologies

- C
- Linux / Ubuntu
- POSIX system calls
- `/proc` filesystem
- Process management
- Linux signals
- File I/O
- File descriptors
- GDB
- strace
