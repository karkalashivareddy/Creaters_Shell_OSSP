Shell Architecture:

The mini shell implements a Read-Eval-Print Loop (REPL):
1. Display prompt
2. Read user input (character by character)
3. Parse and evaluate the command
4. Print result
5. Loop back to step 1

Supported Commands:
  help    - Display available commands
  pwd     - Print current working directory
  echo    - Print text to stdout
  clear   - Clear the terminal screen
  exit    - Exit the shell
  quit    - Exit the shell
  (any other) - Execute as external command via fork()+execvp()

Keyboard Input Handling:

1. Enter Key (\\n / \\r):
   - Terminates current input
   - Null-terminates the buffer
   - Processes the command
   - Resets buffer position
   - Redisplays prompt

2. Backspace (127 / 8):
   - Decrements buffer position
   - Erases last character on screen
   - Uses \\b space \\b sequence for visual erase

3. Ctrl+D (EOF, value 4):
   - Clean exit from shell

4. Ctrl+C (SIGINT):
   - Signal handler restores terminal
   - Prints goodbye message
   - Exits cleanly

5. Regular Characters (32-126):
   - Appended to input buffer
   - Echoed to screen
   - Buffer overflow protection (MAX_INPUT=256)

Input Buffer Management:
  - Fixed-size buffer of 256 characters
  - Position tracker (pos) for current insertion point
  - Backspace prevents underflow (pos > 0 check)
  - Input prevents overflow (pos < MAX_INPUT - 1)

Terminal Mode:
  - Raw mode: disables ICANON (canonical mode) and ECHO
  - Characters available immediately without waiting for Enter
  - Terminal settings restored on exit or signal
